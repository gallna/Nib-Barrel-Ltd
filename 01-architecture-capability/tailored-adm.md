# Tailored ADM

| Status | Owner | Version |
|---|---|---|
| Approved | Architecture Lead | 1.0 |

We follow the ADM phases with lighter outputs. A typical cycle takes **8–12 weeks of part-time effort**.

| Phase | Full TOGAF output | Our tailored output | Typical effort |
|---|---|---|---|
| Preliminary | Org model for EA, tailored framework, principles | This document, [principles](architecture-principles.md), [charter](architecture-charter.md) | Once, reviewed yearly |
| A: Vision | Statement of Architecture Work, Vision, Stakeholder map | Single [Architecture Vision](../02-architecture-landscape/strategic/architecture-vision.md) doc combining all three | 1 week |
| B: Business | Business Architecture document, catalogues, matrices | Capability map, value stream, process list, actor catalogue | 1–2 weeks |
| C: Data | Data Architecture, catalogues, matrices | Data entity catalogue, system-of-record matrix, CRUD matrix | 1 week |
| C: Application | Application Architecture | App portfolio catalogue, interface catalogue, context diagram | 1 week |
| D: Technology | Technology Architecture | Technology catalogue + SIB update | 2–3 days |
| E: Opportunities & Solutions | Consolidated gaps, work packages | Gap table + work package list in [roadmap](../02-architecture-landscape/strategic/architecture-roadmap.md) | 2–3 days |
| F: Migration Planning | Implementation & Migration Plan | Transition architectures in the [roadmap](../02-architecture-landscape/strategic/architecture-roadmap.md) | 2–3 days |
| G: Implementation Governance | Architecture Contracts, compliance reviews | [Contracts](../06-architecture-requirements/architecture-contracts/), [compliance assessments](../05-governance-log/compliance-assessments/) | Ongoing |
| H: Change Management | Change requests, re-entry to ADM | Quarterly review of drivers; triggers a new cycle when needed | Quarterly |
| Requirements Management | Requirements repository | [Requirements catalogue](../06-architecture-requirements/requirements-catalog.md) | Ongoing |

## Triggers for a new ADM cycle
- Revenue growth > 50% year on year
- A new sales channel or country
- A system of record reaching end of contract or end of life
- A significant incident (data breach, extended outage, >1% order error rate in a month)
