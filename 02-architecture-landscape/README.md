# Architecture Landscape

TOGAF divides the landscape into three levels of granularity:

| Level | Here | Scope |
|---|---|---|
| **Strategic** | [`strategic/`](strategic/) | Whole enterprise, 2–3 year horizon |
| **Segment** | [`segment/`](segment/) | One end-to-end value stream, 12–18 months |
| **Capability** | [`capability/`](capability/) | One capability in enough detail to build, 3–6 months |

Each domain document holds **Baseline** (as at 2026-03) and **Target** (end of 2027) side by side, so the gaps are visible without a separate document.
